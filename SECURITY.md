# Security policy

This repository is a pre-release CI control plane. Do not publish suspected
vulnerabilities, credentials, exploit details, or repository-specific evidence
in a public issue.

Report security concerns through GitHub's private vulnerability reporting flow:

<https://github.com/koios-ai/ci-platform/security/advisories/new>

Include the affected immutable commit, the smallest safe reproduction, and the
security boundary involved. Remove or redact secrets and private consumer data.
The public pre-release remains non-authoritative while a report is assessed.
